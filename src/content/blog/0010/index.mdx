## BookCard の改修

NDLサーチが提供する書影 API のサービスが終了したことにより、画像が表示されなくなっていた。

これに関しては代わりになるような API が見つからなかったため、「既存のブックカードにOGP 画像が書影であるようなサイトのリンクを添付し、その画像を代わりに表示する」という方法で対応した。

端的に言えば、 **書誌情報付きリンクカード** を実装した。

https://aktars-blog.com/blog/test_bookcard/

基本的にはブクログのリンクを貼る予定。

## その他いろいろ

上二つの改修と合わせて、`global.css`のリファクタリングを行ったり、OGP画像をキャッシュするようにしたり、細かい変更を色々した。

見てわかるような変化はほぼないので（あと細かいことは忘れてしまったので）割愛。
